# OTT 메인 ERD

회원가입과 영상 조회·재생, 한·영 자막 선택을 제공하는 OTT 서비스입니다.

## 주요 기능

- 이름·로그인 ID·비밀번호를 이용한 회원가입과 세션 기반 로그인
- 비로그인 상태에서 공개 영상 목록·상세 조회
- 로그인한 회원의 영상 재생과 제공되는 한국어·영어 자막 선택
- 영상의 공개·비공개 상태 구분

## ERD

회원, 영상, 자막의 데이터 구조입니다. 영상과 자막은 1:N 관계이며, 회원은 시청 이력을 저장하지 않아 영상과 직접 연결하지 않습니다.

## 주요 컬럼을 둔 이유

| 컬럼 | 사용 목적 |
|---|---|
| `member_id` · `login_id` | 내부 회원 식별값과 로그인 ID를 구분합니다. 로그인 ID는 중복을 허용하지 않습니다. |
| `password_hash` | 비밀번호 원문 대신 해시값을 저장해 로그인 시 검증합니다. |
| `thumbnail_key` · `video_key` | S3에 저장한 썸네일·영상 파일을 식별합니다. CDN 도메인과 분리해 저장합니다. |
| `duration_seconds` | 영상 재생 길이를 초 단위로 저장합니다. |
| `status` | 영상의 공개 여부를 PUBLIC·PRIVATE로 구분합니다. |
| `video_id` · `language` | 자막을 해당 영상과 연결하고 한국어(ko)·영어(en)를 구분합니다. 같은 영상의 같은 언어는 하나만 두도록 두 컬럼에 복합 UNIQUE 제약을 적용합니다. |
| `subtitle_key` | 영상과 별도로 저장한 VTT 자막 파일을 찾습니다. |
| `created_at` | 회원 가입 시각과 영상 등록 시각을 서버에서 기록합니다. |
