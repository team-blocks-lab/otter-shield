# 사내 게시판 ERD

한국·독일 본사 직원이 사용하는 칭찬·점심 공유 게시판입니다.

## 주요 기능

- 세션 기반 직원 번호 로그인과 최초 비밀번호·닉네임 설정
- 칭찬·점심 글을 같은 화면에서 조회하는 피드
- 게시글 등록과 본인 글 수정·삭제
- 칭찬 글의 익명 선택과 선택 사진 1장 첨부 계획

## ERD

직원과 게시글의 1:N 관계, 작성자 연결, 글 종류·익명 여부·사진 식별값·작성 시각을 나타냅니다.

## 주요 컬럼을 둔 이유

| 컬럼 | 사용 목적 |
|---|---|
| `employee_id` | 게시글을 실제 작성자와 연결해 본인 글의 수정·삭제 권한을 확인합니다. 닉네임을 바꾸거나 익명으로 작성해도 연결은 유지합니다. |
| `password_hash` | 로그인 비밀번호 원문을 저장하지 않고 해시값으로 검증합니다. |
| `first_login` | 최초 비밀번호·닉네임 설정이 필요한 계정인지 구분합니다. 설정을 모두 저장한 뒤 false로 변경합니다. |
| `anonymous` | 칭찬 글에서 닉네임 표시와 익명 표시를 선택합니다. 점심 글은 false만 허용합니다. |
| `image_key` | 선택 첨부한 사진을 찾는 식별값입니다. 사진 파일 자체와 구분하며, 첨부하지 않으면 NULL로 둡니다. |
